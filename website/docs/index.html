HttpDash documentation

How every part of HttpDash works, in detail. For what HttpDash is and a quick start, see the README; for what changed in each version, the changelog.

Getting started

  • Install and updateDownload the latest version from the releases page.
  • Import and export everythingExport (top bar) offers two formats.
  • Keyboard shortcutsCtrl on Windows and Linux, Cmd on macOS. They also appear in the menus.
  • Features at a glanceEverything HttpDash does, in one list: requests, responses, scripts, organisation, the runner, import and export, and the tools.
